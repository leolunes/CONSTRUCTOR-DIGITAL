# PLAN DIRECTOR Y MATRIZ DE COBERTURA MGA WEB
# CONSTRUCTOR MGA PRO
# Versión 1.0
# Objetivo: ordenar el desarrollo para que la app entregue el 100% de componentes requeridos para diligenciar la MGA Web.

====================================================================
0. PRINCIPIO RECTOR
====================================================================

Constructor MGA Pro no debe limitarse a generar textos.
Debe construir un proyecto integral de inversión pública con:

1. Formulación MGA.
2. Presupuesto APU.
3. Indicadores.
4. Riesgos.
5. Cronograma.
6. Fuentes de financiación.
7. Documentos técnicos.
8. Validación de coherencia.
9. Memoria inteligente.
10. Mapa de traslado a MGA Web.

La MGA Web será el destino de registro.
Constructor MGA Pro será el motor técnico que prepara toda la información.


====================================================================
1. MATRIZ DE COBERTURA GENERAL MGA WEB
====================================================================

La siguiente matriz clasifica los componentes necesarios en tres estados:

CUBIERTO:
La app ya tiene datos o módulos funcionales.

PARCIAL:
La app tiene una base, pero falta estructura, validación, conexión o detalle.

PENDIENTE:
El componente todavía debe desarrollarse.

4. HOJA DE RUTA PARA LLEGAR AL 100%
====================================================================

FASE 1: MAPA MGA WEB
--------------------------------------------------
Crear:
js/asistente/mga-web/matriz-mga-web.js

Función:
Mapear cada campo requerido por MGA Web con:
- módulo de la app;
- estado;
- fuente de datos;
- motor responsable;
- prioridad;
- validación.


FASE 2: MÓDULOS FALTANTES
--------------------------------------------------
Crear módulos:

1. Identificación MGA.
2. Política pública.
3. Participantes.
4. Población.
5. Alternativas.
6. Beneficios cuantificados.
7. Financiación por vigencias.
8. Sostenibilidad estructurada.


FASE 3: PUENTE PRESUPUESTO - MGA
--------------------------------------------------
Crear:
js/asistente/mga-web/puente-presupuesto-mga.js

Debe conectar:
- capítulos del presupuesto con productos;
- ítems con actividades;
- APUs con insumos;
- costos con cadena de valor;
- costos con vigencias;
- costos con fuentes.


FASE 4: INSPECTOR MGA WEB
--------------------------------------------------
Crear:
js/asistente/mga-web/inspector-mga-web.js

Debe validar:
- campos completos;
- campos parciales;
- campos faltantes;
- coherencia entre módulos;
- presupuesto conectado;
- indicadores completos;
- riesgos completos;
- fuentes equivalentes al valor total.


FASE 5: PANEL DE COBERTURA MGA WEB
--------------------------------------------------
Crear:
js/asistente/mga-web/panel-cobertura-mga-web.js
css/panel-cobertura-mga-web.css

Debe mostrar:
- porcentaje de avance;
- componentes completos;
- componentes incompletos;
- campos pendientes;
- próximos pasos;
- botón copiar para MGA Web;
- botón exportar ficha.
