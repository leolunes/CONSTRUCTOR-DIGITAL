============================================================
1. PROPÓSITO
============================================================

El Motor Inspector es el encargado de revisar la calidad integral del
proyecto antes de considerarlo listo para su presentación o preparación
para la MGA Web.

Su función principal es evaluar, no generar.

============================================================
2. MISIÓN
============================================================

Verificar automáticamente que el proyecto sea consistente, completo,
coherente y técnicamente sólido.

============================================================
3. RESPONSABILIDADES
============================================================

• Revisar la cobertura MGA Web.
• Detectar información faltante.
• Detectar inconsistencias.
• Emitir advertencias.
• Emitir errores críticos.
• Calcular un puntaje de calidad.
• Recomendar acciones correctivas.

============================================================
4. ENTRADAS
============================================================

- Proyecto completo.
- Cobertura MGA.
- Presupuesto.
- Cadena de valor.
- Indicadores.
- Riesgos.
- Cronograma.
- Documentos.

============================================================
5. SALIDAS
============================================================

- Informe de calidad.
- Puntaje general.
- Porcentaje de cobertura.
- Errores críticos.
- Advertencias.
- Recomendaciones.
- Estado "Listo / No listo".

============================================================
6. VALIDACIONES
============================================================

Debe verificar como mínimo:

✓ Datos básicos completos.
✓ Identificación MGA.
✓ Problema y objetivo coherentes.
✓ Árboles completos.
✓ Participantes.
✓ Población.
✓ Alternativas.
✓ Cadena de valor.
✓ Indicadores.
✓ Riesgos.
✓ Cronograma.
✓ Presupuesto.
✓ Fuentes.
✓ Documentos.
✓ Sostenibilidad.

============================================================
7. NIVELES DE RESULTADO
============================================================

Excelente
90 - 100

Bueno
75 - 89

Aceptable
60 - 74

Insuficiente
Menor de 60

============================================================
8. ERRORES CRÍTICOS
============================================================

Ejemplos:

• Proyecto sin problema central.
• Proyecto sin objetivo general.
• Actividades sin presupuesto.
• Productos sin indicadores.
• Valor de fuentes diferente al valor del proyecto.
• Cronograma vacío.

============================================================
9. ADVERTENCIAS
============================================================

Ejemplos:

• Indicadores sin línea base.
• Riesgos sin mitigación.
• Documento sin actualizar.
• Cobertura parcial.
• Beneficiarios incompletos.

============================================================
10. RELACIÓN CON OTROS MOTORES
============================================================

Recibe información de todos los motores.

Entrega información a:

- Copiloto.
- Memoria.
- Panel de Cobertura.
- Usuario.

============================================================
11. EVOLUCIÓN PREVISTA
============================================================

Versión 1:
Lista de validaciones.

Versión 2:
Puntaje técnico.

Versión 3:
Auditor inteligente.

Versión 4:
Recomendaciones predictivas.

============================================================
12. OBJETIVO FINAL
============================================================

Convertirse en el auditor técnico permanente del Constructor MGA Pro,
garantizando que cada proyecto alcance un nivel adecuado de calidad
antes de su radicación o exportación.
