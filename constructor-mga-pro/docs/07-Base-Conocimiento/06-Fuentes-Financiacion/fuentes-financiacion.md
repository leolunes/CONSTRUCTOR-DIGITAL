============================================================
PROPÓSITO
============================================================

Este documento define el catálogo base de fuentes de financiación que
utilizará el Constructor MGA Pro para estructurar financieramente los
proyectos de inversión pública.

Las fuentes de financiación permitirán relacionar el presupuesto,
las vigencias, el cronograma financiero y la preparación para la MGA Web.

============================================================
ESTRUCTURA DE CADA FUENTE
============================================================

Cada fuente deberá contener:

• Nombre.
• Tipo de recurso.
• Nivel de gobierno.
• Descripción.
• Usos permitidos.
• Restricciones.
• Distribución por vigencias.
• Requisitos.
• Observaciones.

============================================================
REGLAS
============================================================

1. Toda fuente debe tener un tipo claramente definido.
2. El total de las fuentes debe coincidir con el valor total del proyecto.
3. Debe permitirse distribuir recursos por vigencias.
4. Cada fuente podrá asociarse a productos y actividades cuando aplique.
5. El Inspector validará la consistencia financiera.

============================================================
INTEGRACIÓN CON PRESUPUESTO PRO
============================================================

El Constructor MGA Pro utilizará el presupuesto generado para:

• Distribuir costos por fuente.
• Distribuir costos por vigencia.
• Calcular participación porcentual.
• Generar cuadros financieros.
• Alimentar la MGA Web.

============================================================
OBJETIVO FINAL
============================================================

Disponer de una biblioteca estructurada de fuentes de financiación que
permita soportar la estructuración financiera del proyecto y mantener
coherencia entre el presupuesto, el cronograma y la MGA Web.
