============================================================
PROPÓSITO
============================================================

Este documento constituye el catálogo base de sectores utilizado por el
Motor de Conocimiento para clasificar proyectos de inversión pública.

Cada sector servirá como punto de partida para:

• Identificar tipologías.
• Sugerir productos MGA.
• Proponer actividades.
• Recomendar indicadores.
• Asociar riesgos.
• Relacionar normatividad.

============================================================
ESTRUCTURA DE CADA SECTOR
============================================================

Cada sector deberá contener:

• Nombre.
• Código (cuando aplique).
• Descripción.
• Tipologías asociadas.
• Productos frecuentes.
• Indicadores frecuentes.
• Riesgos frecuentes.
• Normatividad relacionada.

============================================================
REGLAS
============================================================

1. Cada tipología pertenecerá a un sector principal.
2. Un producto MGA podrá reutilizarse entre sectores cuando corresponda.
3. Toda ampliación del catálogo deberá conservar esta estructura.
4. El Motor de Conocimiento consultará este catálogo antes de sugerir
   tipologías o productos.
