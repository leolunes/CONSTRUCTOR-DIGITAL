============================================================
PROPÓSITO
============================================================

Este documento define el catálogo base de riesgos que utilizará el
Constructor MGA Pro para construir matrices de riesgo durante la
formulación de proyectos de inversión pública.

Cada riesgo podrá asociarse a sectores, tipologías, productos,
actividades y etapas del proyecto.

============================================================
ESTRUCTURA DE CADA RIESGO
============================================================

Cada registro deberá contener:

• Sector.
• Tipología.
• Nombre del riesgo.
• Descripción.
• Categoría.
• Probabilidad.
• Impacto.
• Nivel de riesgo.
• Medidas de mitigación.
• Responsable sugerido.
• Etapa del proyecto.
• Observaciones.

============================================================
CATEGORÍAS
============================================================

• Técnico.
• Financiero.
• Jurídico.
• Ambiental.
• Social.
• Predial.
• Contractual.
• Operativo.
• Climático.
• Institucional.

============================================================
EJEMPLO 1
============================================================

Sector:
Transporte

Tipología:
Placa huella

Riesgo:
Retrasos por temporada de lluvias.

Categoría:
Climático.

Probabilidad:
Alta.

Impacto:
Alto.

Mitigación:
Programar actividades críticas en época seca y contar con plan de
contingencia.

============================================================
EJEMPLO 2
============================================================

Sector:
Agua Potable

Riesgo:
Interferencia con redes existentes.

Categoría:
Técnico.

Mitigación:
Realizar localización de redes y coordinación con empresas de servicios.

============================================================
REGLAS
============================================================

1. Toda tipología deberá tener riesgos mínimos asociados.
2. Todo riesgo deberá contar con una medida de mitigación.
3. El Inspector verificará que existan riesgos para proyectos complejos.
4. Los riesgos podrán reutilizarse entre tipologías compatibles.
