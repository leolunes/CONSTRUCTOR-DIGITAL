============================================================
PROPÓSITO
============================================================

Este documento define la estructura oficial de las tipologías de
proyectos que utilizará el Motor de Conocimiento.

Cada tipología constituye una ficha técnica reutilizable para asistir
la formulación automática de proyectos.

============================================================
ESTRUCTURA DE UNA TIPOLOGÍA
============================================================

Cada tipología deberá documentar:

• Sector.
• Nombre de la tipología.
• Descripción.
• Problema central frecuente.
• Causas comunes.
• Efectos comunes.
• Objetivo general.
• Objetivos específicos.
• Productos MGA.
• Actividades sugeridas.
• Indicadores sugeridos.
• Riesgos frecuentes.
• Fuentes de financiación.
• Normatividad relacionada.
• Observaciones técnicas.

============================================================
EJEMPLO 1
============================================================

Sector

Transporte

Tipología

Mejoramiento de vía rural mediante placa huella.

Problema frecuente

Dificultad de movilidad por deterioro de la vía.

Objetivo general

Mejorar las condiciones de movilidad mediante la construcción de placa
huella.

Productos habituales

• Placa huella construida.
• Obras de drenaje.
• Señalización.

Indicadores

• Metros lineales construidos.
• Tiempo de desplazamiento reducido.

Riesgos

• Lluvias.
• Predios.
• Interferencias de redes.

============================================================
EJEMPLO 2
============================================================

Sector

Agua Potable

Tipología

Optimización de acueducto.

Problema frecuente

Cobertura insuficiente y baja continuidad del servicio.

Objetivo general

Mejorar el suministro de agua potable para la población beneficiaria.

Productos habituales

• Redes instaladas.
• Tanques.
• Equipos.
• PTAP optimizada.

============================================================
REGLAS
============================================================

1. Cada tipología pertenece a un sector principal.
2. Una tipología puede reutilizar productos comunes.
3. Toda tipología debe contar con indicadores y riesgos mínimos.
4. Las fichas podrán ampliarse sin modificar el código.
