============================================================
PROPÓSITO
============================================================

Este documento define las plantillas reutilizables que utilizará el
Constructor MGA Pro para generar automáticamente los distintos
componentes de un proyecto de inversión pública.

Las plantillas garantizan uniformidad, coherencia metodológica y
agilidad en la formulación.

============================================================
TIPOS DE PLANTILLAS
============================================================

1. Diagnóstico

Estructura sugerida:

• Contexto.
• Situación actual.
• Problema identificado.
• Evidencias.
• Necesidad de intervención.

------------------------------------------------------------

2. Problema Central

• Descripción.
• Magnitud.
• Localización.
• Población afectada.

------------------------------------------------------------

3. Árbol de Problemas

• Problema central.
• Causas directas.
• Causas indirectas.
• Efectos directos.
• Efectos indirectos.

------------------------------------------------------------

4. Objetivo General

• Acción principal.
• Beneficiarios.
• Resultado esperado.

------------------------------------------------------------

5. Objetivos Específicos

Cada objetivo deberá:

• Contribuir al objetivo general.
• Ser medible.
• Relacionarse con productos.

------------------------------------------------------------

6. Justificación

• Necesidad.
• Beneficios.
• Impacto esperado.
• Relación con planes y políticas.

------------------------------------------------------------

7. Cadena de Valor

• Productos.
• Actividades.
• Metas.
• Indicadores.

------------------------------------------------------------

8. Sostenibilidad

• Técnica.
• Financiera.
• Institucional.
• Ambiental.
• Social.

------------------------------------------------------------

9. Cronograma

• Actividades.
• Duración.
• Vigencias.
• Responsables.

------------------------------------------------------------

10. Resumen Ejecutivo

• Descripción.
• Objetivos.
• Beneficiarios.
• Presupuesto.
• Resultados esperados.

============================================================
REGLAS
============================================================

1. Las plantillas deben ser reutilizables.
2. Deben permitir personalización.
3. No reemplazan la revisión técnica del usuario.
4. Serán utilizadas por el Motor Generador.
