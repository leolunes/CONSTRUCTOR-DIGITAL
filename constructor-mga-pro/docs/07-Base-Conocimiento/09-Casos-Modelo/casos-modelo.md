============================================================
PROPÓSITO
============================================================

Este documento define la estructura oficial para almacenar proyectos de
referencia que servirán como patrones de formulación para el Motor de
Conocimiento, el Copiloto y el Motor Generador.

Un caso modelo no reemplaza el análisis del usuario; funciona como una
guía técnica basada en experiencias reutilizables.

============================================================
OBJETIVOS
============================================================

• Reutilizar buenas prácticas.
• Reducir tiempos de formulación.
• Mantener coherencia metodológica.
• Facilitar el aprendizaje de la plataforma.
• Apoyar la generación de proyectos similares.

============================================================
ESTRUCTURA DE CADA CASO
============================================================

Cada caso deberá incluir:

• Nombre del proyecto.
• Sector.
• Tipología.
• Descripción.
• Problema central.
• Objetivo general.
• Objetivos específicos.
• Productos.
• Actividades.
• Indicadores.
• Riesgos.
• Presupuesto de referencia.
• Fuentes de financiación.
• Cronograma de referencia.
• Lecciones aprendidas.
• Observaciones técnicas.

============================================================
REGLAS
============================================================

1. Todo caso deberá indicar su fuente.
2. La información deberá anonimizarse cuando provenga de proyectos reales.
3. Los casos deberán actualizarse periódicamente.
4. Los casos servirán como referencia, no como copia automática.
5. Cada caso deberá poder ampliarse con nuevos componentes.

============================================================

============================================================

============================================================
OBJETIVO FINAL
============================================================

Construir una biblioteca de proyectos modelo que permita al
Constructor MGA Pro acelerar la formulación, mejorar la calidad de las
recomendaciones y apoyar la generación de proyectos consistentes a
partir de experiencias previamente documentadas.
