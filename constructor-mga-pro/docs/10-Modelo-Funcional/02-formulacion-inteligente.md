# 02 — Formulación Inteligente

## Propósito

Este documento define el proceso de formulación inteligente del Constructor MGA Pro.

Su objetivo es establecer el algoritmo funcional que seguirá la plataforma para transformar una idea inicial en un proyecto de inversión pública técnicamente estructurado y preparado para MGA Web.

No describe código.

Describe la forma en que debe razonar el sistema.

---

# Principio rector

El Constructor MGA Pro no llena formularios.

Formula proyectos.

Cada componente deberá construirse únicamente cuando exista suficiente información para sustentarlo.

---

# Flujo general de formulación

```text
Idea del usuario
        ↓
Comprender la necesidad
        ↓
Identificar contexto
        ↓
Construir hipótesis inicial
        ↓
Validar conocimiento disponible
        ↓
Formular propuesta técnica
        ↓
Verificar coherencia
        ↓
Completar información faltante
        ↓
Integrar presupuesto
        ↓
Evaluar calidad
        ↓
Preparar MGA Web
```

---

# Paso 1 — Comprender la idea

Antes de escribir cualquier componente el sistema deberá identificar:

- Qué desea hacer el usuario.
- Dónde.
- Para quién.
- Qué problema intenta resolver.
- Qué beneficio espera generar.

Si la información es insuficiente, deberá identificar exactamente qué hace falta.

---

# Paso 2 — Clasificar el proyecto

El sistema consultará el Motor de Conocimiento para identificar:

- Sector.
- Programa.
- Tipología.
- Producto MGA.
- Posibles líneas de inversión.

Cada recomendación deberá estar sustentada.

---

# Paso 3 — Construir una hipótesis

Con la información disponible elaborará una primera hipótesis técnica del proyecto.

Esta hipótesis servirá como base para formular:

- Diagnóstico.
- Problema.
- Objetivos.
- Productos.

La hipótesis podrá ajustarse durante el proceso.

---

# Paso 4 — Formular progresivamente

La formulación deberá seguir un orden lógico.

Nunca se construirán indicadores antes de tener productos.

Nunca se formularán actividades antes de definir los productos.

Nunca se propondrá un presupuesto sin actividades.

Cada componente dependerá del anterior.

---

# Paso 5 — Validar cada componente

Después de generar cada componente el sistema deberá preguntarse:

- ¿Es coherente?
- ¿Está suficientemente sustentado?
- ¿Existe información contradictoria?
- ¿Requiere intervención del usuario?

Solo si la respuesta es satisfactoria continuará con el siguiente componente.

---

# Paso 6 — Solicitar información

Cuando el sistema no pueda formular con un nivel adecuado de confianza deberá detener el proceso y solicitar únicamente la información necesaria.

Las preguntas deberán ser:

- concretas;
- técnicas;
- priorizadas;
- fáciles de responder.

Nunca deberá pedir información innecesaria.

---

# Paso 7 — Integrar

Cuando la formulación técnica esté consolidada se integrarán:

- Presupuesto.
- APUs.
- Cronograma.
- Riesgos.
- Fuentes.
- Documentos.

---

# Paso 8 — Evaluar

Antes de finalizar se ejecutarán:

- Motor de Razonamiento.
- Motor de Calidad.
- Inspector MGA.
- Asesor Experto.
- Semáforo de Radicación.

Las observaciones deberán consolidarse antes de generar el resultado final.

---

# Paso 9 — Preparar MGA Web

El sistema preparará:

- Textos.
- Resúmenes.
- Reportes.
- Componentes exportables.

La información deberá conservar la trazabilidad con Project Core.

---

# Reglas de formulación

- Comprender antes de escribir.
- Sustentar antes de recomendar.
- Validar antes de avanzar.
- Reutilizar antes de crear.
- Registrar todas las decisiones importantes.

---

# Resultado esperado

Al finalizar este proceso el Constructor MGA Pro deberá entregar un proyecto técnicamente consistente, con alto nivel de automatización y preparado para su revisión y diligenciamiento en MGA Web.
