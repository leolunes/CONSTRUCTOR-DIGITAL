# 05 — Modelo de Calidad

## Propósito

Este documento define el modelo funcional de calidad del Constructor MGA Pro.

Su finalidad es establecer los criterios con los cuales la plataforma evaluará si un proyecto de inversión pública alcanza el nivel técnico esperado para ser presentado a una entidad pública y posteriormente diligenciado en la MGA Web.

No describe validaciones aisladas.

Define el estándar de calidad profesional que deberá cumplir toda formulación realizada por el Constructor MGA Pro.

---

# Objetivo

Garantizar que cada proyecto formulado sea:

- Coherente.
- Completo.
- Sustentable.
- Trazable.
- Defendible técnicamente.

La calidad no dependerá únicamente de que todos los campos estén diligenciados.

Dependerá de la consistencia integral del proyecto.

---

# Principios

- Evaluar antes de aprobar.
- Comprender antes de calificar.
- Fundamentar cada observación.
- Priorizar la calidad sobre la velocidad.
- Mantener criterios homogéneos para todos los proyectos.

---

# Dimensiones de calidad

El Constructor MGA Pro evaluará las siguientes dimensiones:

## Calidad conceptual

Verifica que la necesidad pública esté correctamente comprendida.

Incluye:

- Diagnóstico.
- Problema.
- Justificación.
- Contexto.

---

## Calidad lógica

Verifica la relación entre:

Problema → Objetivo General

Objetivos → Productos

Productos → Actividades

Actividades → Presupuesto

Indicadores → Metas

Riesgos → Mitigación

---

## Calidad técnica

Evalúa:

- Claridad.
- Precisión.
- Consistencia.
- Terminología.
- Fundamentación.

---

## Calidad presupuestal

Comprueba:

- Correspondencia entre actividades y costos.
- Consistencia de APUs.
- Costos directos.
- Costos indirectos.
- Fuentes de financiación.

---

## Calidad documental

Verifica:

- Documentos requeridos.
- Soportes.
- Justificaciones.
- Reportes.

---

# Niveles de evaluación

Cada componente podrá clasificarse como:

Excelente

Bueno

Aceptable

Requiere fortalecimiento

Crítico

---

# Puntaje general

El sistema calculará un puntaje integral considerando todas las dimensiones de calidad.

El resultado deberá expresarse como:

- Puntaje total.
- Puntaje por componente.
- Nivel alcanzado.
- Riesgos encontrados.
- Recomendaciones priorizadas.

---

# Reglas de evaluación

El sistema nunca calificará únicamente por cantidad de información.

También evaluará:

- Coherencia.
- Relación entre componentes.
- Sustento técnico.
- Calidad de la argumentación.

---

# Integración

Este modelo será utilizado por:

- Motor de Calidad.
- Motor de Razonamiento.
- Maestro MGA.
- Inspector MGA.
- Asesor Experto.
- Semáforo de Radicación.
- Reporte Ejecutivo.

---

# Resultado esperado

Antes de declarar un proyecto listo para MGA Web, el Constructor MGA Pro deberá demostrar que alcanza un nivel suficiente de calidad técnica en todas las dimensiones evaluadas.

La plataforma deberá explicar por qué obtuvo esa calificación y qué acciones permitirían mejorarla.
