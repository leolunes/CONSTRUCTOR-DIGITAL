# 06 — Flujo de Información

## Propósito

Este documento describe cómo circula la información dentro del Constructor MGA Pro, desde el momento en que el usuario registra una idea hasta que el proyecto queda preparado para MGA Web.

Su objetivo es garantizar que todos los componentes trabajen de forma coordinada utilizando una única fuente de información.

---

# Principio fundamental

Toda la información permanente del proyecto vive en el **Project Core**.

Los motores inteligentes analizan esa información.

Los módulos funcionales la presentan, complementan o utilizan.

---

# Flujo general

```text
Usuario
↓
Interfaz
↓
Project Core
↓
Motor Central
↓
Motores Inteligentes
↓
Módulos MGA
↓
Módulos de Presupuesto
↓
Reportes y Exportación
↓
Proyecto listo para MGA Web
```

---

# Etapa 1 — Captura de información

El usuario puede ingresar información mediante:

- Idea inicial.
- Formularios.
- Catálogos.
- Presupuesto.
- APUs.
- Importaciones.
- Edición manual.

Toda la información se registra inicialmente en Project Core.

---

# Etapa 2 — Análisis

El Motor Central consulta Project Core y determina:

- Estado del proyecto.
- Componentes faltantes.
- Inconsistencias.
- Prioridades.

Posteriormente coordina:

- Motor de Conocimiento.
- Motor de Razonamiento.
- Motor de Flujo.
- Motor de Calidad.
- Motor de Aprendizaje.
- Motor de Decisiones.

---

# Etapa 3 — Actualización

Los resultados generados por los motores se consolidan nuevamente en Project Core.

Esto garantiza que exista una única versión oficial del proyecto.

---

# Etapa 4 — Consumo de información

Los módulos especializados consultan Project Core.

Entre ellos:

- Cerebro MGA.
- Formulación Automática.
- Cobertura MGA.
- Inspector MGA.
- Asesor Experto.
- Semáforo.
- Reporte Ejecutivo.
- Exportador MGA.
- Presupuesto.
- APUs.

---

# Etapa 5 — Presentación

La interfaz muestra:

- Estado del proyecto.
- Cobertura.
- Calidad.
- Observaciones.
- Recomendaciones.
- Reportes.
- Documentos.
- Presupuesto.

---

# Integración con Presupuesto

El flujo financiero sigue el mismo principio.

```text
Actividades
↓
Presupuesto
↓
APUs
↓
Costos
↓
Project Core
↓
Reportes
```

---

# Integración con Reportes

Toda la información consolidada permite generar:

- Reporte Ejecutivo.
- Reportes técnicos.
- Reportes presupuestales.
- Exportaciones.
- Información para MGA Web.

---

# Reglas del flujo

- Nunca duplicar información.
- Actualizar siempre Project Core.
- Sincronizar todos los módulos.
- Registrar cambios en el historial.
- Mantener trazabilidad completa.

---

# Beneficios

- Coherencia entre todos los componentes.
- Reducción de inconsistencias.
- Integración automática.
- Escalabilidad.
- Facilidad de mantenimiento.
