# 09-Mapa-Arquitectura — README

## Propósito

La carpeta `09-Mapa-Arquitectura` tendrá como finalidad documentar la arquitectura REAL del Constructor MGA Pro.

A diferencia de la documentación conceptual, esta carpeta describirá la estructura exacta del proyecto tal como existe en Visual Studio Code.

Será el inventario técnico oficial de la plataforma.

---

# Objetivos

- Documentar todas las carpetas existentes.
- Documentar todos los módulos principales.
- Identificar las dependencias entre componentes.
- Explicar el flujo de información.
- Diferenciar los módulos heredados de `presupuesto-pro` de los desarrollados para MGA.
- Facilitar el mantenimiento y la evolución de la plataforma.

---

# Alcance

Esta documentación abarcará toda la aplicación, incluyendo:

- Estructura de carpetas.
- Archivos JavaScript.
- Archivos CSS.
- Datos.
- Documentación.
- Plantillas.
- Catálogos.
- Presupuesto.
- APUs.
- Motores inteligentes.
- Project Core.
- Integraciones.
- PWA.
- Exportadores.
- Reportes.

---

# Principio fundamental

Esta carpeta no describe cómo debería ser la aplicación.

Describe exactamente cómo está construida.

Será la referencia oficial para futuras modificaciones.
