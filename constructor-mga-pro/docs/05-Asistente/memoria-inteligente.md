# CONSTRUCTOR MGA PRO
# Plataforma Inteligente de Formulación de Proyectos de Inversión Pública
# Versión 1.0
# Ubicación:
# docs/05-Asistente/memoria-inteligente.md

============================================================
1. PROPÓSITO
============================================================

La Memoria Inteligente es el componente que permite al Copiloto
recordar el estado de cada proyecto y ofrecer asistencia contextual
durante toda la formulación.

Su finalidad es evitar que el usuario tenga que repetir información y
permitir que el Constructor MGA Pro continúe el trabajo exactamente
donde fue interrumpido.

============================================================
2. OBJETIVOS
============================================================

• Recordar el contexto del proyecto.
• Conservar las decisiones del usuario.
• Mantener un resumen actualizado.
• Recomendar el siguiente paso.
• Facilitar la continuidad entre sesiones.
• Apoyar al Copiloto y al Inspector.

============================================================
3. INFORMACIÓN QUE CONSERVA
============================================================

Datos generales

• Nombre del proyecto.
• Sector.
• Tipología.
• Estado del proyecto.

Formulación

• Problema central.
• Objetivo general.
• Cadena de valor.
• Indicadores.
• Riesgos.
• Documentos.

Presupuesto

• Valor total.
• Estado del presupuesto.
• Integración con la MGA.

Cobertura

• Porcentaje de cobertura MGA Web.
• Componentes completos.
• Componentes pendientes.

============================================================
4. RESUMEN EJECUTIVO INTERNO
============================================================

La Memoria mantendrá un resumen permanente del proyecto.

Ejemplo:

Proyecto:
Mejoramiento de vías rurales.

Estado:
81 % de cobertura MGA Web.

Última actividad:
Actualización de indicadores.

Pendiente:
Relacionar actividades con presupuesto.

Próximo paso:
Completar cronograma físico-financiero.

============================================================
5. CÓMO UTILIZA LA MEMORIA EL COPILOTO
============================================================

Antes de responder al usuario, el Copiloto deberá consultar:

• Estado general.
• Historial resumido.
• Última acción.
• Recomendaciones pendientes.
• Observaciones del Inspector.

Con esta información podrá responder de manera contextualizada.

============================================================
6. RECOMENDACIONES INTELIGENTES
============================================================

La Memoria podrá generar recomendaciones como:

• Continúe con la población objetivo.
• Revise las fuentes de financiación.
• Complete la sostenibilidad.
• Asocie actividades con el presupuesto.
• Revise las advertencias del Inspector.

============================================================
7. HISTORIAL RESUMIDO
============================================================

Cada acción relevante generará un registro.

Ejemplo:

Fecha:
2026-07-10

Acción:
Generación del diagnóstico.

Resultado:
Diagnóstico creado correctamente.

Estado:
Pendiente revisar objetivos específicos.

============================================================
8. RELACIÓN CON EL INSPECTOR
============================================================

Las observaciones del Inspector pasarán a la Memoria para que el
Copiloto pueda recordarlas incluso en sesiones posteriores.

============================================================
9. RELACIÓN CON LOS MOTORES
============================================================

La Memoria suministrará contexto a:

• Motor Orquestador.
• Motor de Análisis.
• Motor Generador.
• Motor de Coherencia.
• Motor de Autocompletado.
• Inspector.

============================================================
10. EVOLUCIÓN PREVISTA
============================================================

Versión 1:
Resumen del proyecto.

Versión 2:
Memoria contextual por módulo.

Versión 3:
Seguimiento inteligente de avances.

Versión 4:
Asistencia predictiva basada en el historial.

============================================================
11. BENEFICIOS
============================================================

• Continuidad entre sesiones.
• Menor repetición de información.
• Mejor experiencia de usuario.
• Mayor coherencia del proyecto.
• Mejor soporte al Copiloto.
• Base para futuras automatizaciones.

============================================================
12. OBJETIVO FINAL
============================================================

Convertir la Memoria Inteligente en el contexto permanente del
Constructor MGA Pro, permitiendo que el usuario, el Copiloto y todos
los motores trabajen siempre sobre un conocimiento actualizado del
estado real del proyecto.
