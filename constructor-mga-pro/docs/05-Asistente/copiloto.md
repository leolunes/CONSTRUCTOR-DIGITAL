============================================================
1. PROPÓSITO
============================================================

El Copiloto es la interfaz inteligente entre el usuario y los motores
del Constructor MGA Pro.

Su función es acompañar al formulador durante todo el ciclo de vida del
proyecto, guiándolo paso a paso hasta obtener una formulación completa y
lista para la MGA Web.

No reemplaza al usuario.

Lo asiste, recomienda, explica y automatiza tareas repetitivas.

============================================================
2. OBJETIVOS
============================================================

• Guiar el proceso de formulación.
• Interpretar solicitudes en lenguaje natural.
• Invocar el Motor Orquestador.
• Explicar conceptos metodológicos.
• Recomendar el siguiente paso.
• Informar el estado del proyecto.
• Presentar resultados comprensibles.

============================================================
3. FUNCIONES PRINCIPALES
============================================================

1. Conversar con el usuario.
2. Comprender la intención.
3. Solicitar información faltante.
4. Generar recomendaciones.
5. Activar motores inteligentes.
6. Explicar observaciones del Inspector.
7. Ayudar a completar la MGA.
8. Facilitar la navegación por módulos.

============================================================
4. TIPOS DE CONSULTAS
============================================================

El usuario podrá solicitar, por ejemplo:

• Crear un proyecto.
• Analizar una idea.
• Mejorar el diagnóstico.
• Generar objetivos.
• Revisar riesgos.
• Relacionar presupuesto y actividades.
• Generar documentos.
• Preparar la MGA Web.
• Identificar información faltante.

============================================================
6. INFORMACIÓN QUE DEBE MOSTRAR
============================================================

• Estado del proyecto.
• Cobertura MGA Web.
• Próximo paso recomendado.
• Errores críticos.
• Advertencias.
• Resumen ejecutivo interno.
• Actividad reciente.

============================================================
7. PRINCIPIOS DE DISEÑO
============================================================

• Lenguaje claro.
• Respuestas técnicas.
• Explicaciones breves.
• Transparencia sobre las acciones ejecutadas.
• Respeto por las decisiones del usuario.
• No modificar información confirmada sin autorización.

============================================================
8. RELACIÓN CON LA MEMORIA
============================================================

Antes de responder, el Copiloto consultará la Memoria Inteligente para
conocer:

• Estado del proyecto.
• Últimas acciones.
• Recomendaciones pendientes.
• Historial resumido.
• Cobertura MGA.

============================================================
9. RELACIÓN CON EL INSPECTOR
============================================================

El Copiloto traducirá los resultados del Inspector en recomendaciones
prácticas para el usuario.

Ejemplo:

"El proyecto tiene una cobertura del 82 %. Se recomienda completar la
población objetivo y asociar las actividades con el presupuesto."

============================================================
10. EVOLUCIÓN PREVISTA
============================================================

Versión 1:
Asistente conversacional.

Versión 2:
Navegación inteligente por módulos.

Versión 3:
Asistencia predictiva según el estado del proyecto.

Versión 4:
Acompañamiento integral durante toda la formulación.

============================================================
11. OBJETIVO FINAL
============================================================

Convertirse en el principal punto de interacción entre el usuario y la
plataforma, permitiendo formular proyectos de inversión pública con
mayor rapidez, calidad y coherencia metodológica.
