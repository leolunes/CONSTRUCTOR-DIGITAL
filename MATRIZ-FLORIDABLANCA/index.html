Centro de respaldos y traslado de dispositivos

Exporte registros, PDF archivados y fotografías en un solo JSON privado. Para trabajar desde iPhone, iPad y computador, transfiera ese archivo por un medio privado e impórtelo en cada dispositivo. No suba el JSON a GitHub.

Para entregar la aplicación: publique solamente los archivos del programa. Luego exporte el respaldo desde este navegador e impórtelo en la dirección de GitHub Pages. Repita la importación en los demás dispositivos.

Importante: esta importación agrega elementos faltantes pero no sobrescribe los que ya tienen el mismo identificador. Si edita un mismo contacto en dos equipos, esos cambios no se sincronizarán automáticamente. Trabaje con un dispositivo principal y haga respaldos frecuentes.
