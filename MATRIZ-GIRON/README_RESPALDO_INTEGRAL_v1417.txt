MATRIZ GIRÓN v1.4.17 — RESPALDO INTEGRAL Y TRASLADO SEGURO

1. NUNCA suba archivos JSON de respaldo a GitHub o a carpetas públicas.
2. Abra la aplicación ORIGINAL donde están los datos con esta versión instalada en la MISMA dirección/origen.
3. En Configuración > Exportar respaldo integral, descargue el JSON completo.
4. Compruebe que el JSON efectivamente está guardado en Descargas antes de cambiar nada más.
5. Abra la aplicación destino en el navegador del otro dispositivo. Configuración > Seleccionar JSON > Fusionar respaldo.
6. Solo incorpora lo faltante, conserva datos existentes sin reemplazarlos. Pulse Recargar aplicación.
7. Las imágenes de tarjetas descargadas pero no archivadas por la app no pueden reconstruirse desde el JSON.
8. La firma privada no se exporta salvo autorización explícita.
9. Un origen distinto (localhost, 127.0.0.1, GitHub Pages) tiene datos separados. Publicar archivos JS no transfiere datos entre orígenes.
10. La fusión no sincroniza cambios futuros; debe exportar/importar de nuevo cuando corresponda.

Esta edición para publicación no integra registros privados como archivos del código fuente.
