MATRIZ MAESTRA DE GESTIÓN TERRITORIAL PARA GIRÓN - v1.0.0

1. Abra la carpeta en Visual Studio Code.
2. Para probarla localmente, use Live Server sobre index.html.
3. Para GitHub Pages, suba el contenido completo de esta carpeta a un repositorio o subcarpeta publicada.
4. La aplicación guarda la información en localStorage del navegador/dispositivo.
5. Use Configuración > Exportar JSON para realizar respaldos periódicos.
6. Puede restaurar el respaldo en otro navegador con Importar JSON.
7. Al publicarse por HTTPS en GitHub Pages, puede instalarse como PWA en PC, Android, iPhone y iPad.

MÓDULOS INCLUIDOS
- Tablero ejecutivo.
- Necesidades territoriales.
- Líderes / JAC / ediles.
- Proyectos e iniciativas.
- Gestión y seguimiento.
- Formulario comunitario.
- Reportes por Girón y por territorio.
- Exportación CSV.
- Respaldo/restauración JSON.
- PWA con manifest y service worker.

CRITERIO CENTRAL
Necesidad + responsable + próxima acción + fecha = gestión.
