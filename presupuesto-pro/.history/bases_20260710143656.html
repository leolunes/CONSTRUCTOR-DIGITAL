Cómo funciona

Importar varias bases
Todas deben conservar el mismo formato XLSX que la aplicación ya reconoce.
Seleccionar base activa
La base activa se utilizará de forma general mientras los proyectos todavía no tengan una base asignada.
Conservar cada base
Cada importación queda almacenada de manera independiente en IndexedDB.
Preparado para proyectos
En la siguiente etapa, cada proyecto quedará vinculado a la base seleccionada al momento de crearlo.
