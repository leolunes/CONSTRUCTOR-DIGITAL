# 06 — Modelo de Aprendizaje

## Propósito

Este documento define el modelo funcional de aprendizaje del Constructor MGA Pro.

Su finalidad es establecer cómo la plataforma mejora progresivamente sus recomendaciones sin reemplazar el criterio técnico del formulador ni alterar automáticamente la información del proyecto.

El aprendizaje tiene como propósito aumentar la precisión, reducir reprocesos y aprovechar la experiencia acumulada.

---

# Objetivo

Permitir que el Constructor MGA Pro aprenda patrones de formulación para ofrecer recomendaciones cada vez más útiles, manteniendo siempre el Project Core como fuente oficial de información.

---

# Principios

- Aprender sin modificar automáticamente el proyecto.
- Sugerir antes que imponer.
- Conservar la trazabilidad.
- Respetar las decisiones del usuario.
- Priorizar el criterio técnico sobre el aprendizaje.

---

# ¿Qué puede aprender?

## Patrones de formulación

- Sectores más utilizados.
- Tipologías frecuentes.
- Productos MGA más seleccionados.
- Estructuras de proyectos similares.

---

## Preferencias del formulador

- Estilo de redacción.
- Indicadores que suele preferir.
- Riesgos que incorpora habitualmente.
- Fuentes de financiación más utilizadas.

---

## Buenas prácticas

- Soluciones que producen mejores resultados.
- Estructuras con mayor calidad técnica.
- Componentes que reducen observaciones.
- Recomendaciones aceptadas con mayor frecuencia.

---

# ¿Qué NO debe aprender?

El sistema nunca deberá utilizar como aprendizaje:

- Información personal.
- Datos reservados.
- Valores confidenciales.
- Decisiones administrativas particulares.
- Información que comprometa la privacidad del proyecto.

El aprendizaje debe centrarse en patrones técnicos y no en datos sensibles.

---

# Proceso de aprendizaje

```text
Proyecto formulado
        ↓
Resultados obtenidos
        ↓
Identificación de patrones
        ↓
Validación técnica
        ↓
Memoria inteligente
        ↓
Mejores recomendaciones
```

---

# Reglas

Antes de reutilizar un patrón el sistema deberá verificar:

- Que sea técnicamente válido.
- Que sea compatible con el proyecto actual.
- Que no contradiga la normativa.
- Que mejore la calidad de la formulación.

---

# Integración

Este modelo será utilizado por:

- Motor de Aprendizaje.
- Maestro MGA.
- Motor de Conocimiento.
- Motor de Decisiones.
- Asesor Experto.

---

# Resultado esperado

Con el paso del tiempo el Constructor MGA Pro deberá ofrecer recomendaciones más precisas, disminuir preguntas innecesarias y reutilizar buenas prácticas de formulación, sin perder la consistencia técnica ni sustituir el análisis profesional.
