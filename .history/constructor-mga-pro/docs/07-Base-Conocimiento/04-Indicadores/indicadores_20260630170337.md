============================================================
PROPÓSITO
============================================================

Este documento define la estructura oficial del catálogo de indicadores
que utilizará el Constructor MGA Pro para formular proyectos,
construir la Cadena de Valor y preparar la información para la MGA Web.

Los indicadores constituyen el mecanismo principal para medir el logro
de productos, resultados y objetivos.

============================================================
ESTRUCTURA DE CADA INDICADOR
============================================================

Cada indicador deberá contener:

• Sector.
• Tipología.
• Tipo de indicador.
• Nombre.
• Descripción.
• Unidad de medida.
• Línea base.
• Meta.
• Fórmula.
• Fuente de verificación.
• Frecuencia de medición.
• Producto asociado.
• Actividad asociada.
• Observaciones.

============================================================
TIPOS DE INDICADORES
============================================================

• Producto.
• Resultado.
• Gestión.
• Cobertura.
• Calidad.
• Eficiencia.

============================================================
REGLAS
============================================================

1. Todo producto debe tener al menos un indicador.
2. Todo indicador debe tener unidad de medida.
3. Toda meta debe ser medible.
4. Debe existir una fuente de verificación.
5. Debe indicarse la frecuencia de medición.
