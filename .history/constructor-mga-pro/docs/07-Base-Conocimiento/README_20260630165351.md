# BASE DE CONOCIMIENTO
# CONSTRUCTOR MGA PRO
# Archivo: docs/07-Base-Conocimiento/README.md

============================================================
PROPÓSITO
============================================================

La Base de Conocimiento es el repositorio técnico que alimenta al
Motor de Conocimiento y, por extensión, a todos los motores
inteligentes del Constructor MGA Pro.

Aquí no se almacena código.

Aquí se almacena conocimiento reutilizable.

============================================================
OBJETIVOS
============================================================

• Centralizar el conocimiento técnico.
• Evitar información duplicada.
• Facilitar la actualización de reglas.
• Alimentar los motores inteligentes.
• Mantener trazabilidad de las fuentes.

============================================================
REGLAS
============================================================

1. Toda información deberá indicar su fuente.
2. Evitar duplicidad de contenido.
3. Mantener un formato homogéneo.
4. Las actualizaciones no deben requerir cambios en el código.
5. El Motor de Conocimiento consultará esta base antes de generar
   recomendaciones.

============================================================
